# Projetos em Flutter

## 🥠 projeto_aula02

Projeto temático de biscoito da sorte, utilizando lista e FloatingActionButton. Aprendendo conceitos e o básico da criação de projetos.

## ↕️ projeto_aula03

Projeto utilizado para aprender sobre criação de telas, mainAxisAlignment e style.

## ↔️ projeto_aula04 e projeto_aula04_casa

Projetos de realização de exercícios utilizando column, row, padding e etc. Exercícios de widgets de layout.

## 🖼 projeto_aula05

Projeto de realização de exercícios utilizando diferentes widgets. Utilização de asset,TextButton,ListView e outros.

## 🍰 projeto_aula06

Projeto com foto na componentização de itens ja trabalhados.

## 🧮 projeto_aula07

Projeto destinado a aprendizado de Stateful widgets + itens já trabalhados.

## 📸 projeto_aula08

Projeto de rede social (post + story) com crud em memória e logo após adaptado para crud com persistência local com sqlite

## 🛒 projeto_aula09

Projeto feito individualmente como avaliação do segundo trimestre da disciplina de desenvolvimento de aplicativos. Aplicativo "ToBuy" é uma lista de compras com entrada para dados em texto e com um showDatePicker para validade de produtos, contém flag e Crud de uma tabela.
